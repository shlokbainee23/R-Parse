## 3. Visual Inconsistencies & Token Divergence Matrix

| Visual Dimension | Landing Page Standard | Studio Current Implementation | Recommended Unified Token |
| :--- | :--- | :--- | :--- |
| **Canvas Background** | Deep Graphite (`--window-deep: #16161A`) | Warm Ivory (`--bg-page: #F7F5F0`) | `--bg-canvas: #121216` |
| **Panel Surfaces** | Elevated Glass (`--window-deep-surface: #1E1E24`) | Stark White (`--bg-panel: #FFFFFF`) | `--bg-panel: #1A1A20` |
| **Card Surfaces** | Deep Card (`--window-deep-card: #25252D`) | White (`--bg-card: #FFFFFF`) | `--bg-card: #22222A` |
| **Primary Accent** | Signal Orange (`--accent-orange: #FF5A1F`) | Orange aliased as Blue (`--accent-blue: #FF5A1F`) | `--accent-primary: #FF5A1F` |
| **Dataflow Accent** | Glowing Lilac (`--accent-lilac: #B8A6FF`) | Deep Violet (`--accent-purple: #7C3AED`) | `--accent-dataflow: #B8A6FF` |
| **Primary Typography** | `Plus Jakarta Sans` / `General Sans` | `Plus Jakarta Sans` | `--font-sans: 'Plus Jakarta Sans', system-ui, sans-serif` |
| **Monospace / Code** | `JetBrains Mono` | `JetBrains Mono` | `--font-mono: 'JetBrains Mono', monospace` |
| **Borders & Dividers** | Muted White Rules (`rgba(255,255,255,0.10)`) | Muted Dark Rules (`rgba(18,18,18,0.08)`) | `--border-subtle: rgba(255, 255, 255, 0.08)` |
| **Container Geometry** | Large radius (`16px`, `24px`, pill buttons) | Small radius (`4px`, `6px`, `10px`) | `--radius-sm: 4px; --radius-md: 8px; --radius-lg: 14px` |
| **Motion Curve** | Editorial Ease (`cubic-bezier(0.16, 1, 0.3, 1)`) | Standard ease (`ease`, `0.15s`) | `--ease-spring: cubic-bezier(0.16, 1, 0.3, 1)` |

## 4. Architectural Opportunities for Shared Component Primitives

1. **Unified Design Token System (`tokens.css`):**
   Extract CSS custom properties into a single shared design system token contract covering surface levels (L0 Canvas through L4 Drawer), colorways (Signal Orange, Dataflow Lilac, Emerald Kept, Rose Dropped, Amber Uncertainty), typography scales, and spring motion curves.
2. **Unified Navigation Bar Primitive:**
   Replace the bloated 76px 2-row Studio header with a single 44px bar matching the landing page header's glassmorphism and typographic restraint.
3. **Unified Code Block & Line Gutter Primitive:**
   Unify the line-numbering and character-span highlighting renderer between the Landing Page Exhibit 01/04 code cards and the Studio Source Pane.
4. **Docked Workspace Layout vs Overlay Hack:**
   Replace the floating `position: absolute` inspector overlay with an integrated third pane or smart canvas pan offset, eliminating target occlusion entirely.
